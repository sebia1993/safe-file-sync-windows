# 오류코드 안내

SafeFileSync 0.1.0-alpha.4부터 화면의 **코드만 복사** 버튼은 아래 표의 고정된 3자리 문자열 하나만 클립보드에 넣습니다. 예: `S03`. 직접 코드만 입력해 전달해도 됩니다.

경로, 파일명, 서버 주소, 계정, 작업 ID, 시각, 파일 내용이나 해시, 원시 Windows/Robocopy 오류 번호, 로그를 붙이거나 코드에 인코딩하지 않습니다. 메시지 내용을 해석하거나 해시로 줄여 만든 코드가 아닙니다. 외부 서버로 진단을 자동 전송하지 않습니다. 일반 상세 화면·작업 DB·보고서·로그에는 내부 정보가 남을 수 있으며 이 버튼은 그런 자료를 복사하지 않습니다.

| 코드 | 의미 | 확인할 내용 |
|---|---|---|
| S01 | 입력 또는 옵션 오류 | 모든 원본 경로, 중복 없는 목적지 폴더 이름, 절대 경로 형식을 확인합니다. |
| S02 | 원본 관련 경로 겹침 | 원본끼리 또는 원본과 목적지가 같거나 서로 포함되는지 확인합니다. 실제 경로 별칭도 검사합니다. |
| S03 | 내부 기록과 선택 폴더의 겹침 | 시스템 드라이브 전체 대신 전송할 폴더를 선택합니다. 프로그램이 안전 조건을 확인할 수 있는 원본·목적지 구성으로 새 작업을 시작하세요. 기록 경로 설정은 필요하지 않습니다. |
| S04 | 접근 권한 또는 인증 오류 | 현재 Windows 계정의 폴더·공유 권한과 인증 상태를 확인합니다. 내부 기록을 만들 권한이 없거나 기존 기록의 소유자·허용 권한이 안전하지 않은 경우에도 표시합니다. 권한 확인이 필요하면 사내 담당자에게 코드와 발생 동작을 전달하세요. |
| S05 | 경로 또는 드라이브 사용 불가 | 지정 폴더의 존재 여부와 네트워크 드라이브 연결 여부를 확인합니다. |
| S06 | 네트워크 연결 오류 | 공유 연결, 서버 응답 및 네트워크 상태를 확인합니다. |
| S07 | 파일 또는 폴더 사용 중 | 해당 파일을 사용하는 프로그램을 확인하고 저장·종료 후 재시도합니다. |
| S08 | 저장 공간 부족 | 임시 복사본과 기록을 저장할 공간을 확인합니다. |
| S09 | 링크 또는 안전성 확인 불가 | 링크·Junction·하드링크나 안정적인 파일 식별을 지원하지 않는 항목을 확인합니다. |
| S10 | 원본 변경 감지 | 작업 또는 중지 중 원본 변경을 확인합니다. 최초 기준을 유지해 경고하며, 변경 내용을 새 기준으로 삼으려면 새 작업을 시작합니다. |
| S11 | 복사 도구 실패 | 전송을 완료하지 못했습니다. 연결·권한·파일 상태를 내부에서 확인하고 재시도합니다. |
| S12 | 검증 미완료 | 누락·불일치·검사 불가 항목이 남았거나 임시 복사본 검증에 실패했습니다. 완료로 간주하지 않습니다. |
| S13 | 목적지 기존 항목 충돌 | 보존 정책 또는 파일/폴더 충돌을 확인합니다. 기존 파일을 교체하려는 경우에만 검증 후 교체를 선택합니다. |
| S14 | 작업 기록 또는 재개 조건 오류 | 기록 위치·DB 상태와 저장된 원본/목적지/검증 정책을 확인합니다. 구성을 바꾸려면 새 작업을 시작합니다. |
| S15 | 작업 중지 | 전송·검증 미완료입니다. 이력에서 재개할 수 있습니다. |
| S16 | 기타 입출력 오류 | 파일 시스템 작업을 완료하지 못했습니다. 연결·저장 장치 상태를 내부에서 확인합니다. |
| S99 | 분류되지 않은 오류 | 이 코드만으로 세부 원인을 확정할 수 없습니다. |

코드는 원인 **범주**이며 개별 파일이나 상세 로그를 복원할 수 없습니다. 여러 오류가 있으면 안전성·구체적인 원인을 우선하여 대표 코드 하나를 표시하므로, 그 문제를 해결한 뒤 다른 코드가 나타날 수 있습니다. 새 작업은 이전 코드를 지우고 다시 검사합니다. 정상 비교에서 발견된 일반적인 누락·차이·목적지 추가 항목 자체는 오류코드로 표시하지 않지만, 비교 중 접근 실패나 링크 제외는 표시합니다. 빠른 검증은 여전히 전체 내용 검증을 의미하지 않습니다.

클립보드를 사용할 수 없으면 원래 코드가 화면에 남으므로 직접 입력할 수 있습니다.

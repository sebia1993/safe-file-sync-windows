SafeFileSync 0.1.0-alpha.5 — 사용자 폴더 밖의 기본 기록 위치

기본 기록 위치를 AppData에서 Windows 설치 드라이브의 최상위 폴더로 변경했습니다. 보통 C:\SafeFileSync에 기록하므로 사용자 폴더 전체를 원본으로 선택할 때 기본 기록 위치가 원본에 포함되지 않습니다.

- 실제 기록 폴더 미리보기와 ‘기본 위치’ 버튼 추가
- 앱 시작·이력 조회에서는 폴더를 만들지 않고, 작업의 모든 원본·목적지 겹침 검사가 끝난 뒤 생성
- 신규 기본 기록 폴더의 권한을 현재 사용자·SYSTEM·Administrators로 제한하고, 기존 기본 폴더의 소유자·허용 권한 검사
- 권한 문제는 S04로 안내하고 다른 쓰기 가능한 기록 위치를 선택하도록 처리; 기존 ACL 변경이나 AppData 자동 전환 없음
- 기존 AppData 기록 이동·삭제 없음; 이전 실제 기록 기준 폴더를 다시 선택하면 기존 이력 사용 가능
- 다중 원본·네트워크 드라이브·원본 보호·코드만 복사 기능 유지

C:\ 전체가 원본이면 기록 위치도 원본에 포함되므로 다른 드라이브에서 모든 원본·목적지 밖의 폴더를 선택하세요. 직접 선택한 다른 기록 기준 폴더는 기존 권한을 유지합니다.

ZIP에서 SafeFileSync.App.exe를 꺼내 실행하세요. .NET·SQLite가 포함된 단일 EXE이며 EXE만 별도로 옮겨 실행할 수 있습니다. SHA256SUMS로 다운로드 파일 무결성을 확인할 수 있습니다.

코드는 원인 범주를 구분하며 내부 상세 로그를 복원하지 않습니다. 일반 보고서·로그·상세 화면에는 내부 경로가 포함될 수 있습니다. 앱이 외부로 진단을 자동 전송하지 않습니다.

Windows CI, loopback SMB 및 자동 UI 검증과 실제 사내 환경 검증은 구분합니다. 실행 파일은 아직 서명되지 않았으며 실제 사내 EDR/DLP·네트워크 단절·Windows 11 현장 수용 검증은 남아 있습니다. 빠른 검증은 내용의 완전한 일치를 증명하지 않으며 ACL/ADS 전체 복제는 지원하지 않습니다.

SafeFileSync 0.1.0-alpha.2 — 사용자 폴더 전송 시 작업 기록 위치 선택

사용자 폴더 전체를 원본으로 선택하면 기본 AppData 기록 위치가 원본 안에 있어 시작이 차단되던 사용 흐름을 개선했습니다.

- 화면에 `기록 위치` 선택/입력 추가. 선택한 기존 폴더 아래 SafeFileSync에 DB·로그·보고서를 저장합니다.
- 원본/목적지와 겹치는 기록 위치는 계속 차단하고 변경 방법을 안내합니다.
- 선택한 기록 위치의 이력 불러오기와 재개를 지원합니다. 앱 재실행 후 같은 위치를 다시 선택하세요.
- SMB 공유를 드라이브 문자로 연결한 목적지 루트로의 전송 회귀 검사를 추가했습니다.

ZIP에서 SafeFileSync.App.exe를 꺼내 실행하세요. .NET·SQLite가 포함된 단일 EXE이며 EXE만 별도로 옮겨 실행할 수 있습니다. SHA256SUMS로 다운로드 파일 무결성을 확인할 수 있습니다.

원본과 목적지 네트워크 드라이브는 유지하고 `기록 위치`를 양쪽 폴더 밖의 쓰기 가능한 기존 폴더로 지정하세요.

Windows CI, loopback SMB 및 자동 UI 검증 범위와 실제 사내 환경 검증은 구분합니다. 실행 파일은 아직 서명되지 않았으며 실제 사내 EDR/DLP·네트워크 단절·Windows 11 현장 수용 검증은 남아 있습니다. 빠른 검증은 내용의 완전한 일치를 증명하지 않으며 ACL/ADS 전체 복제는 지원하지 않습니다.
